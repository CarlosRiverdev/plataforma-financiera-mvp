# Calculadora de interés simple y compuesto

Propuesta de front-end en **Next.js (App Router) + TypeScript + Tailwind CSS**, con las gráficas hechas en **Chart.js**. Cuatro ventanas: interés simple, interés compuesto, comparación e historial.

## Cómo correrlo

```bash
npm install
npm run dev
```

Se abre en `http://localhost:3000`.
